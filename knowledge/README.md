# Knowledge base

The business context every department reads. These files are **templates with
placeholders** (`[[ … ]]`). Fill them in to make the agents sharper.

> ⚠️ **This repository is public.** Before you type real staff names, salaries,
> customer details, vendor rates or Drive file IDs here, make the repo **private**
> (GitHub → Settings → General → Danger Zone → Change visibility). Until then, keep
> those details in a private Google Doc or Sheet and add only its *name* here.

| File | Used by | What to fill in |
|---|---|---|
| `company.md` | all | Company profile, segments, USP, locations |
| `brand.md` | Marketing | Voice, colours, logo use, do's and don'ts |
| `team.md` | HR, Sales, Chief of Staff | Roles, who owns which data, reporting lines |
| `products.md` | Sales, Product, Marketing | Catalogue, own-manufactured vs traded, price bands |
| `customers.md` | Sales, Finance, Ops | Key accounts, segments, credit status |
| `vendors.md` | Finance, Ops, Product | Suppliers, fabricators, terms, priority |
| `opportunities.md` | Research | Expansion and tender pipeline |
| `data-sources.md` | all | Where each kind of data lives and how to read it |
| `policies/sales.md` | Sales | Discount authority, margin floor, incentive slabs |
| `policies/finance.md` | Finance | Minimum cash, advance and credit rules, payment priority |
| `policies/hr.md` | HR | Attendance, leave, OT, conduct |
